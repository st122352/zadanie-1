# Задание 1 — прочность бетона при сжатии

## Коротко о результате

По составу смеси и возрасту образца можно получить полезную оценку прочности на этом наборе данных. Лучше всего на случайной тестовой выборке сработала физически мотивированная линейная модель: её RMSE составила **7,82 МПа**, тогда как у обычной линейной регрессии — **10,48 МПа**. Однако при проверке на образцах старше 90 суток качество заметно снижается. Поэтому модель подходит для учебного анализа данных, но не для расчёта реальных бетонных конструкций.

## Данные и проверяемые ожидания

Использован набор [Concrete Compressive Strength, UCI, №165](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength), опубликованный I‑Cheng Yeh. В нём 1 030 образцов, восемь входных признаков и измеренная прочность. Семь признаков — количество цемента, шлака, золы-уноса, воды, суперпластификатора и двух видов заполнителя в **кг/м³**; восьмой — **возраст образца в сутках**. Целевая величина — прочность при сжатии в **МПа**. UCI указывает лицензию **CC BY 4.0**; атрибуция приведена в [описании данных](data/README.md).

До построения моделей были сформулированы три ожидания:

- с возрастом образца прочность растёт, хотя эта связь может быть нелинейной;
- более высокое отношение воды к суммарному вяжущему связано с меньшей прочностью;
- большее количество вяжущего связано с большей прочностью.

Это гипотезы об ассоциациях в наблюдаемой выборке, а не утверждения о причинном эффекте изменения рецептуры.

## Насколько хорошо предсказывают модели

Данные случайно разделены на обучающую часть (80%) и тестовую (20%). Параметры моделей выбирались с помощью вложенной кросс-валидации. Все ошибки указаны в МПа; чем меньше RMSE и MAE, тем лучше, а более высокое R² означает лучшее соответствие данным.

| Модель | Train: MAE / RMSE / R² | CV: MAE / RMSE / R² | Тест: MAE / RMSE / R² |
|---|---:|---:|---:|
| Среднее обучающей выборки | 13,39 / 16,61 / 0,000 | 13,40 / 16,61 / −0,001 | 13,71 / 17,07 / −0,003 |
| OLS по исходным признакам | 8,14 / 10,33 / 0,613 | 8,23 / 10,45 / 0,604 | 8,52 / 10,48 / 0,622 |
| Физически мотивированная (PHYS) | **5,49 / 7,05 / 0,819** | **5,52 / 7,12 / 0,816** | **6,15 / 7,82 / 0,790** |
| Ridge | 8,16 / 10,33 / 0,613 | 8,25 / 10,45 / 0,604 | 8,54 / 10,50 / 0,620 |
| Lasso | 8,19 / 10,35 / 0,612 | 8,26 / 10,46 / 0,603 | 8,57 / 10,53 / 0,618 |
| Квадратичная модель с Ridge | 5,46 / 7,08 / 0,818 | 5,98 / 7,84 / 0,777 | 6,49 / 8,42 / 0,756 |

PHYS представляет состав через общее количество вяжущего и несколько отношений между компонентами, а возраст — через логарифм. Это удобная для интерпретации параметризация, а не нормативная формула бетона.

PHYS показала лучшее качество на случайном тесте, и её результаты на обучении, в кросс-валидации и на тесте близки. Ridge и Lasso почти не изменили качество OLS. Квадратичная модель уловила нелинейность, но её ошибка выше, а разрыв между обучением и проверкой больше — это признак некоторого переобучения. [Кривая ошибки при настройке регуляризации](figures/regularization_curve.svg).

## Проверка на другом диапазоне возраста

Чтобы проверить перенос на более старые образцы, все образцы **старше 90 суток** были исключены из обучения. Модели обучались на образцах до 90 суток; качество сравнивалось как на отложенной части этого же возрастного диапазона, так и на образцах старше 90 суток.

| Модель | До 90 суток: RMSE / R² | Старше 90 суток: RMSE / R² |
|---|---:|---:|
| Среднее | 15,82 / −0,001 | 20,32 / −1,486 |
| OLS | 7,81 / 0,756 | 50,71 / −14,483 |
| PHYS | **6,79 / 0,816** | **9,87 / 0,414** |
| Ridge | 7,80 / 0,757 | 50,60 / −14,413 |
| Lasso | 7,75 / 0,760 | 49,66 / −13,847 |
| Квадратичная + Ridge | 6,37 / 0,838 | 284,42 / −486,011 |

Отрицательное R² означает, что прогноз оказался хуже простого предсказания средним значением тестовой группы. OLS и квадратичная модель резко теряют точность за пределами возраста, на котором обучались. PHYS переносится лучше остальных, но её RMSE всё равно растёт с 6,79 до 9,87 МПа. Следовательно, хорошая оценка на случайном разбиении сама по себе не гарантирует надёжный прогноз для нового возрастного режима.

## Что показывают коэффициенты и остатки

Устойчивость коэффициентов PHYS проверялась 500 bootstrap-перевыборками. Для трёх основных признаков знак сохранялся во всех повторах:

| Признак | Медианный коэффициент | 95% bootstrap-интервал | Знак сохранялся |
|---|---:|---:|---:|
| Вода / вяжущее | −84,20 | [−97,85; −71,10] | 100% |
| log(возраста в сутках) | +8,76 | [+8,35; +9,20] | 100% |
| Общее вяжущее, кг/м³ | +0,071 | [+0,051; +0,093] | 100% |

Коэффициенты измеряются в МПа на единицу соответствующего признака; для общего вяжущего единица признака — кг/м³, а отношения и log(возраста) безразмерны.

Коэффициенты относятся к признакам PHYS и показывают условные связи внутри этой модели. Для исходной OLS-модели оценки отдельных заполнителей менее надёжны: их bootstrap-интервалы включают ноль. В исходных данных вода и суперпластификатор также заметно связаны между собой (корреляция −0,657), поэтому разделить их независимые эффекты трудно. Регуляризация меняет величины отдельных коэффициентов, но почти не улучшает прогноз OLS.

Диагностика остатков PHYS не выявила заметной линейной связи ошибки с самим прогнозом или отношением воды к вяжущему. С возрастом остаётся слабый тренд: корреляция составляет −0,175. Это согласуется с тем, что перенос на возраст старше 90 суток хуже обычной случайной проверки.

## Вывод

В рамках этого набора данных PHYS — наиболее удачный и устойчивый вариант среди рассмотренных моделей. Наблюдения поддерживают ожидаемые связи: прочность выше при большем количестве вяжущего и большем возрасте, и ниже при большем отношении воды к вяжущему. При этом оценки отдельных компонентов зависят от их взаимной корреляции, а перенос на возраст старше 90 суток остаётся ограниченным. Результаты описывают конкретный датасет и не заменяют экспериментальные испытания или инженерные нормы.

Подробные таблицы предсказаний, метрик, коэффициентов и проверок сохранены в папке `results/`; графики представлены в формате SVG в папке `figures/`.
