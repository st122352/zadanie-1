# Задание 1 — прогноз прочности бетона

## Цель и источник данных

Цель — оценивать лабораторно измеренную прочность бетонного образца при сжатии по составу смеси и возрасту образца. Использован набор [Concrete Compressive Strength, UCI, №165](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength), автор — I‑Cheng Yeh. По карточке UCI, набор содержит 1 030 наблюдений, 8 количественных признаков, одну количественную целевую переменную и не содержит пропусков. Исходные файлы включены в `data/`; UCI указывает лицензию **CC BY 4.0**. Атрибуция и библиографическая ссылка приведены в [data/README.md](data/README.md).

Целевая величина — прочность при сжатии, МПа. Семь компонентов смеси измерены в кг/м³ смеси: цемент, доменный шлак, зола-унос, вода, суперпластификатор, крупный и мелкий заполнители. Восьмой признак — возраст образца в сутках. Это лабораторный набор конкретных составов и возрастов, а не репрезентативная выборка всех бетонов и условий твердения.

## Проверяемые до обучения гипотезы

1. При прочих равных увеличение возраста связано с повышением прочности, но прибавка не обязана оставаться линейной. В модели проверяется положительный знак коэффициента `log(age)`.
2. Рост отношения воды к суммарному вяжущему (цемент + шлак + зола-унос) связан со снижением прочности. Проверяется отрицательный знак `water/binder`.
3. Большая общая дозировка вяжущего связана с большей прочностью при фиксированном представлении долей компонентов. Проверяется положительный знак `binder_total`.

Это проверяемые условные ассоциации в наблюдательных данных, не причинные эффекты.

## Модели и протокол оценки

- **MEAN:** константный прогноз среднего train-значения.
- **OLS:** линейная регрессия по 8 исходным количествам и возрасту.
- **PHYS:** линейная модель с общим вяжущим, отношением вода/вяжущее, долями шлака и золы в вяжущем, отношением суперпластификатор/вяжущее, отношением заполнители/вяжущее и `log(age)`. Это интерпретируемая физически мотивированная параметризация, а не нормативная формула бетона.
- **RIDGE, LASSO:** регуляризованные линейные модели по исходным 8 признакам; признаки стандартизируются только на обучающей части.
- **POLY2_RIDGE:** квадратичные члены и попарные взаимодействия исходных признаков плюс Ridge-регуляризация; выбранная на случайном train-разбиении сила штрафа мала (`α = 10⁻⁵`).

Случайное разбиение: 824 строки на обучение (80%) и 206 на тест (20%), seed `20261110`. CV-метрики получены из вложенной оценки: внешние 5 складок для оценки обобщения, внутренние 4 — для выбора `α`. Масштабирование и настройка выполняются внутри складок. MAE и RMSE приведены в МПа; большее R² означает лучшее соответствие.

## Метрики: train / cross-validation / random test

В каждой ячейке указано `MAE / RMSE / R²`.

| Модель | Train | Вложенная CV | Тест 20% |
|---|---:|---:|---:|
| MEAN | 13,39 / 16,61 / 0,000 | 13,40 / 16,61 / −0,001 | 13,71 / 17,07 / −0,003 |
| OLS | 8,14 / 10,33 / 0,613 | 8,23 / 10,45 / 0,604 | 8,52 / 10,48 / 0,622 |
| PHYS | **5,49 / 7,05 / 0,819** | **5,52 / 7,12 / 0,816** | **6,15 / 7,82 / 0,790** |
| Ridge | 8,16 / 10,33 / 0,613 | 8,25 / 10,45 / 0,604 | 8,54 / 10,50 / 0,620 |
| Lasso | 8,19 / 10,35 / 0,612 | 8,26 / 10,46 / 0,603 | 8,57 / 10,53 / 0,618 |
| Квадратичная + Ridge | 5,46 / 7,08 / 0,818 | 5,98 / 7,84 / 0,777 | 6,49 / 8,42 / 0,756 |

Физически мотивированная модель лучше остальных на случайной тестовой выборке. Её разница train–CV мала; квадратичная модель показывает больший разрыв (RMSE 7,08 train против 7,84 CV и 8,42 test), то есть умеренное переобучение. Ridge и Lasso почти не улучшают OLS на исходных признаках. Полиномиальные члены заметно повышают качество относительно OLS, но не превосходят PHYS и ухудшают перенос за границы возраста.

Кривые 4-fold CV RMSE по `α` показывают, что для линейных Ridge/Lasso ошибка почти плоская на широком диапазоне штрафов: настройка регуляризации сама по себе не устраняет ограничения линейной модели. Для квадратичной модели выбран почти нулевой Ridge-штраф (`α = 10⁻⁵`), поэтому на случайном разбиении она хорошо аппроксимирует нелинейность, но остаётся очень неустойчивой при экстраполяции. [График CV RMSE по `α`](figures/regularization_curve.svg); полные значения — `results/regularization_curve.csv`.

## Проверка на отложенном диапазоне возраста

Отдельно все образцы старше 90 суток исключены из обучения. Для сопоставления интерполяции и переноса обучение проводилось на одной и той же подвыборке возрастов ≤90 суток (`n=715`), а оценка — на случайной части ≤90 суток (`n=179`) и на всех образцах >90 суток (`n=136`).

| Модель | Интерполяция ≤90: MAE / RMSE / R² | Перенос >90: MAE / RMSE / R² |
|---|---:|---:|
| MEAN | 12,44 / 15,82 / −0,001 | 16,35 / 20,32 / −1,486 |
| OLS | 5,74 / 7,81 / 0,756 | 35,91 / 50,71 / −14,483 |
| PHYS | **5,17 / 6,79 / 0,816** | **8,16 / 9,87 / 0,414** |
| Ridge | 5,74 / 7,80 / 0,757 | 35,80 / 50,60 / −14,413 |
| Lasso | 5,73 / 7,75 / 0,760 | 34,90 / 49,66 / −13,847 |
| Квадратичная + Ridge | 4,81 / 6,37 / 0,838 | 157,53 / 284,42 / −486,011 |

Негативное R² означает, что модель хуже константного среднего тестовой группы. Линейная модель по исходным данным экстраполирует эффект возраста почти линейно и резко теряет качество за 90 суток; квадратичная модель становится крайне неустойчивой вне диапазона. Логарифм возраста в PHYS уменьшает, но не устраняет провал переноса: RMSE возрастает с 6,79 до 9,87 МПа, а R² падает с 0,816 до 0,414. Поэтому случайную CV-оценку нельзя использовать как замену проверке нового возрастного режима.

Все 7 исходных дозировок для образцов >90 суток лежат внутри отдельных min–max диапазонов обучающей части ≤90 суток. Поэтому проверка направлена на перенос по возрасту, хотя новые сочетания дозировок всё равно могут отличаться от сочетаний в обучении.

## Физические гипотезы и устойчивость коэффициентов

Bootstrap выполнен 500 раз на случайной обучающей выборке. Ниже — оценки PHYS в единицах признака; интервалы — 2,5-й и 97,5-й процентили bootstrap-распределения. Ранг эффекта считается по модулю коэффициента, умноженного на стандартное отклонение соответствующего признака; это позволяет сопоставлять безразмерные отношения и дозировки.

| Признак | Медианный коэффициент | 95% bootstrap-интервал | Знак в bootstrap | Медианный ранг эффекта |
|---|---:|---:|---:|---:|
| Вода / вяжущее | −84,20 МПа на единицу отношения | [−97,85; −71,10] | отрицательный в 100% | 1 |
| log(возраста, сутки) | +8,76 МПа на единицу log | [+8,35; +9,20] | положительный в 100% | 2 |
| Общее вяжущее, кг/м³ | +0,071 МПа на кг/м³ | [+0,051; +0,093] | положительный в 100% | 3 |
| Заполнители / вяжущее | +5,10 МПа на единицу отношения | [+3,66; +6,42] | положительный в 100% | 4 |
| Доля золы-уноса в вяжущем | −22,00 МПа на единицу доли | [−26,14; −17,71] | отрицательный в 100% | 5 |
| Доля шлака в вяжущем | −9,37 МПа на единицу доли | [−12,19; −6,60] | отрицательный в 100% | 6 |
| Суперпластификатор / вяжущее | +75,31 МПа на единицу отношения | [+17,39; +136,96] | положительный в 99,8% | 7 |

Гипотезы о положительной связи общего вяжущего и возраста и отрицательной связи вода/вяжущее устойчивы в этой спецификации и bootstrap-перевыборке. Наивная трактовка отдельных коэффициентов состава требует осторожности: замена части одного компонента другим одновременно меняет несколько соотношений.

У исходных компонентов наибольшая по модулю парная корреляция — вода с суперпластификатором (`r = −0,657`); число обусловленности стандартизованной матрицы 8 признаков равно 8,77. В raw-OLS коэффициенты цемента, шлака, золы, воды и возраста сохраняют знак во всех bootstrap-перевыборках. Для крупного и мелкого заполнителей интервалы коэффициентов включают ноль, а положительный знак встречается примерно в 87% bootstrap-повторов. В Lasso коэффициент мелкого заполнителя сжимается ровно к нулю. Ridge и Lasso почти не меняют CV-качество, но меняют размеры малых коэффициентов. Значит, качественные выводы по воде/вяжущему, общему вяжущему и возрасту устойчивее, чем выводы о независимом эффекте каждого заполнителя и точном ранжировании всех компонентов.

Эти знаки остаются ассоциациями в конкретной выборке и модели; они не доказывают, что отдельное изменение рецептуры причинно вызовет такое изменение прочности.

## Остатки и графики

Для теста PHYS корреляция остатка с предсказанием равна −0,079, с вода/вяжущее `+0,072` — линейной зависимости почти нет. С возрастом корреляция −0,175, то есть слабый остаточный тренд сохраняется; средний остаток в случайном тесте для образцов старше 90 суток равен −2,64 МПа (остаток = факт − прогноз). Это согласуется с ухудшением age-range transfer и показывает, что модель не полностью описывает зависимость прочности от возраста.

## Вывод

В случайном тесте лучшей оказалась физически мотивированная линейная модель на общих количествах вяжущего и пропорциях компонентов плюс `log(age)`. Она улучшает тестовый RMSE с 10,48 МПа у OLS до 7,82 МПа. Основные ожидаемые направления (больше вяжущего и возраста — выше прочность; больше воды на единицу вяжущего — ниже) стабильны при bootstrap и разумной регуляризации. Отдельные коэффициенты заполнителей чувствительны к совместному изменению состава.

Ключевое ограничение — экстраполяция по возрасту: только PHYS переносит на >90 суток без катастрофического роста ошибки, но её R² всё равно снижается до 0,414. Все оценки относятся к этому датасету и не должны использоваться как инженерная формула проектирования бетона.
