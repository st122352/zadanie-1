# Источник данных и атрибуция

Набор **Concrete Compressive Strength** (UCI Machine Learning Repository, dataset 165), автор набора — I-Cheng Yeh. Данные пожертвованы UCI 3 августа 2007 г.; исходное описание указывает лабораторно измеренную прочность образца в зависимости от состава смеси и возраста.

UCI сообщает лицензию **CC BY 4.0**. При повторном использовании сохраняйте атрибуцию: I-Cheng Yeh, “Modeling of strength of high performance concrete using artificial neural networks,” *Cement and Concrete Research*, 28(12), 1797–1808 (1998), а также ссылку на страницу набора UCI.

- Страница набора: <https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength>
- Лицензия CC BY 4.0: <https://creativecommons.org/licenses/by/4.0/>
- Файлы исходного набора: `Concrete_Data.xls` и `Concrete_Readme.txt`.
