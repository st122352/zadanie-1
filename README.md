# Прочность бетона при сжатии — анализ регрессии

Воспроизводимый учебный анализ набора [Concrete Compressive Strength, UCI, dataset 165](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength). Цель — сравнить простую базовую оценку, OLS, физически мотивированное представление состава, Ridge, Lasso и полиномиальную модель второй степени; проверить качество на случайном тесте и при переносе на возраст образцов старше 90 суток.

## Запуск

Python 3.10+:

```powershell
python -m pip install -r requirements.txt
python analysis.py
```

Исходный Excel UCI включён в `data/Concrete_Data.xls`; интернет для запуска не нужен. Результаты перезаписываются в `results/`, графики — в `figures/`. Сводка с выводами находится в [report.md](report.md).

## Что делает скрипт

- использует фиксированный seed `20261110` и случайное разбиение 80/20;
- масштабирует признаки внутри каждой обучающей складки, без утечки из проверки;
- подбирает регуляризацию во внутренней кросс-валидации и оценивает её внешней 5-fold CV;
- сохраняет train/CV/test метрики MAE, RMSE и R²;
- сохраняет CV-кривые ошибки по силе регуляризации;
- отдельно сравнивает случайный holdout до 90 дней и перенос на все наблюдения старше 90 дней;
- оценивает стабильность знака и ранга коэффициентов по 500 bootstrap-перевыборкам;
- сохраняет предсказания, остатки, коэффициенты, диагностические графики и метаданные.

Реализация использует NumPy, pandas и Matplotlib; оптимизация линейных моделей написана в самом скрипте, дополнительных ML-библиотек не требуется.
